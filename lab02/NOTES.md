# рабочая папка, индекс, коммит
рабочая папка - папка, в которой хранятся файлы с которыми работаешь напрямую
индекс - готовые к добавлению в коммит изменения
коммит - зафиксированные изменения с сообщением
# различия Git и Github
Git - система контроля версий устанавливаемая локально
Github - облачная платформа для хранения репозиториев и совместной удаленной работы
# Использованные команды 
git status - показывает статус файлов
git diff - показывает разницу между рабочей папкой и индексом
git diff --staged - показывает разницу между индексом и последним коммитом
